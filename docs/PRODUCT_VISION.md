# Product Vision and Commercial Scope

## North star

Build an AI 3D platform that earns a place alongside or ahead of category leaders such as Meshy and Tripo through measurable output quality, artist control, speed, production compatibility and fair pricing. No universal “number 1” ranking is presumed; this is an ambitious goal, not a factual ranking.

## Customers and jobs to be done

- **3D artists and game makers:** create textured props, iterate mesh variants, repair topology, export clean assets.
- **Animation studios and independent creators:** generate and reuse stylized adult characters with stable proportions, facial expressions, motion-ready rigs and Blender compatibility.
- **Environment and scene creators:** assemble terrain, buildings, props and editable scenes; optionally explore Gaussian-splat worlds as a different product mode.
- **Technical teams/API users:** scripted high-volume generation, stable artifact formats, predictable pricing, lineage and webhooks.
- **Designers and 3D-printing users:** use optimized geometry and carefully validated task-specific exports.

## Product tenets

1. **Everything essential in one studio** (generation, edit, rig, preview, export, project library), but behind modular services.
2. **Production quality over preview illusions:** inspect reverse/side views, UVs, materials, skeleton deformations and downstream import—not just front-facing screenshots.
3. **Output ownership clarity:** user terms must distinguish user-upload rights, generated outputs, open-source weight licenses and proprietary first-party technology.
4. **User control:** reproducible seeds where available, model/version selection, part edits, materials, triangle budgets and regeneration history.
5. **Commercial compliance:** no noncommercial research weights in paid services without permission.
6. **Economics:** inference GPU, postprocessing, queue, storage, retries and support all count toward cost.
7. **Distinct differentiator:** high-quality reusable stylized animated characters, including eyes, blinking, brows, jaw, mouth interior, visemes and deformation, plus efficient Blender export.

## Ambition vs realistic execution

- First working release: image/text → mesh → texture → viewer → verified GLB, with secure accounts and jobs.
- Expansion: multi-model routing, multiview, optimized geometry, retopology, body rigging, subscriptions.
- Advanced R&D: facial animation, editable generated scenes, identity persistence and specialized model fine-tuning.
- Longer-term: end-to-end professional studio and developer ecosystem.

## Boundaries

A single input photo cannot guarantee exact hidden 3D geometry. Automatic retopology does not automatically produce deformation-ready faces. Gaussian splats are not the same as an editable polygon scene. AI asset generation is not the same as AI-generated video; the target animation workflow uses actual mesh rigs and Blender animation.

## Business control

The project owner's repository, brand, frontend, backend, credentials, cloud resources, product designs, first-party algorithms and customer relationships should remain independently controllable. The owner does not gain exclusive rights over upstream permissive open-source code or third-party pretrained weights merely by including or fine-tuning them.
