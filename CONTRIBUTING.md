# Contributing to Build 3D AI

Thank you for helping build a real commercial-quality 3D creation platform.

1. Read the [vision](docs/PRODUCT_VISION.md), [feature matrix](docs/FEATURE_MATRIX.md), [architecture](docs/ARCHITECTURE.md) and [agent instructions](AGENTS.md).
2. Choose a task from [BACKLOG](docs/BACKLOG.md); confirm it is not already provided by an approved public library.
3. Record a license decision and a security/cost impact for all new models, weights, datasets and libraries.
4. Implement a narrow end-to-end change with tests and clear user-visible failure behavior.
5. Open a pull request with reproducible setup, tests and what was *not* tested.
6. Do not include credentials, copyrighted training assets without rights, unapproved dependencies, or large model weights in Git.

**Definition of done:** code reviewed, tests pass, real outputs proven where applicable, logs safe, documentation updated and downstream compatibility verified. A planning task is not “done” merely because source code exists.

This repository does not yet publish a blanket contribution or outbound source-code license. Contributors should obtain clarity on contribution rights before adding nontrivial third-party or original code. Third-party license notices must be retained.
